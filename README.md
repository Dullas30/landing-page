# NEOCS: Own Nigeria

Read the attached NEOCS Concept Paper completely before generating anything. Treat it as the authoritative source of truth for the business, vision, products, ecosystem, and terminology. Do not reproduce the document or simply convert it into a webpage. Your task is to transform the information into a world-class landing page that feels like it was designed by an elite product design agency.

This project is ONLY for the public-facing landing page. Do NOT build a dashboard, member portal, authentication, payment flows, forms with backend logic, or any application functionality. Use realistic placeholders where necessary.

PROJECT GOAL

Design an unforgettable premium landing page for the Nigeria Equipment Ownership Cooperative Society (NEOCS).

The page should not feel like an investment website. It should feel like the launch of a national movement centered around productive asset ownership, enterprise growth, community wealth creation, and economic empowerment.

Visitors should leave believing:

 This organization is credible.

 This organization has a serious long-term vision.

 This organization understands Nigeria's challenges.

 This organization is transparent.

 This is bigger than investing money.

 This is about collective ownership of productive assets.

DESIGN STYLE

Create something that could win design awards.

The experience should be cinematic, premium, elegant, modern, sophisticated, minimal, highly interactive, and emotionally engaging.

IMPORTANT

This should not look like a template.

This should feel like the launch of a nationally significant initiative.

Every design decision should reinforce one central idea:

"NEOCS empowers people to collectively own productive assets, build enterprises, create sustainable wealth, and strengthen communities."

The final landing page should feel polished, trustworthy, memorable, and worthy of presentation to stakeholders and potential members.

Use the attached concept paper as the primary reference. Where information is unclear, prioritize clarity, trust, and simplicity over adding unsupported claims.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Other available scripts: `npm run build` (production build), `npm run preview` (preview the production build), `npm run lint`, `npm run format`.
